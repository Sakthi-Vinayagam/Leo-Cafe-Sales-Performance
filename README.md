# ☕ LEO Café Sales Performance

### Interactive analysis of Sales, Products, Locations & Customer Transactions

## 📌 Project Overview

The LEO Café Sales Performance Dashboard is an interactive Power BI project designed to analyze cafe sales and customer transaction data.

The dashboard provides a clear view of sales performance across different products, categories, locations, dates and transaction hours, helping identify sales trends and customer purchasing patterns.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing product categories and products
- Understand sales performance across store locations
- Analyze customer transaction patterns
- Identify peak sales hours
- Compare weekday and weekend sales
- Provide interactive insights using Power BI

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📊 Dashboard Features

- Total Sales analysis
- Sales by Product Category
- Sales by Product Type
- Sales by Store Location
- Sales by Hour
- Weekday vs Weekend analysis
- Interactive Month, Category and Product Type slicers
- KPI-based sales performance tracking

## 📈 Key Insights

The dashboard helps identify:

- Which product categories generate higher sales
- Which products contribute significantly to overall sales
- Which locations perform better
- Peak sales hours during the day
- Differences between weekday and weekend sales
- Monthly sales trends
